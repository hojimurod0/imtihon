# M-IT — Dart bilim imtihoni

## Tuzilishi
1. Kirishda professional kutib olish modal oynasi:
   - M-IT o‘quv markazi
   - 1 oy davomida Dart bilan tanishilganini eslatadi
   - imtihon 2 bosqichdan iboratligini tushuntiradi
   - 60% o‘tish mezonini ko‘rsatadi
   - omad tilaydi
2. Guruh / Ism / Familiya
3. 30 ta nazariy test
4. Alohida o‘tish oynasi
5. 3 ta alohida amaliy topshiriq
6. Amaliy yechimni kod ko‘rinishida kiritish
7. Yakuniy natija:
   - nazariya: 30 ball
   - amaliyot: 3 ball
   - jami: 33 ball
   - foiz
   - 60% va yuqori: IMTIHONdan O‘TDI
   - 60% dan past: IMTIHONdan O‘TMADI — FAILED
   - javoblar tahlili
   - chop etish

## VS Code
ZIP'ni chiqaring → papkani VS Code’da oching → `index.html`ni Live Server bilan oching.

## O‘quvchilar uchun qisqa link
Saytga real internet link berish uchun loyiha GitHub Pages, Netlify yoki sizning hostingingizga joylashtiriladi.
Qisqa ko‘rinish sifatida domen/subdomen ishlatish mumkin, masalan:

`dart.kliro.uz`

Bu manzil loyiha hosting/DNS sozlangandan keyin ishlaydi; hozirgi ZIP ichidagi loyiha lokal ishlaydi.
